# Кабинет «Искры» и вход в интервью

Я принял [F005](../specs/005-iskra-workspace/spec.md) и начал с кабинета по [задачам T01–T04](../specs/005-iskra-workspace/tasks.md). База — `d42c9b10d4be8c20ffe718847d10f1a01119ae17`. [Снимок интервью до переноса входа](ui/desktop-final.jpg) сохранён в предыдущем PR. Версия кода для проверок — `cd258a6d0e509ed98a16913cd9d7710fd1316b0d`.

| Что я хотел проверить | Что показал прогон |
| --- | --- |
| AC1. Путь из кабинета | «Добавить вакансию» открывает существующее интервью. Из введения доступен локальный экран подключения. При выходе после правок появляется подтверждение. Возврат восстанавливает выбранную вакансию и фокус |
| AC2. Связанные данные | В наборе 6 вакансий. Для Frontend Engineer видны 12 откликов, 8 ответов и 5 пройденных тестов. В карте 10 записей, у двух отсутствует зарплата или скор. При смене вакансии обновляются все представления. У вакансии без откликов и у пустой поисковой выдачи разные состояния |
| AC17–18, часть кабинета | Проверены меню, поиск, возврат фокуса и автоматические правила доступности axe. Ленту топ-кандидатов можно прокрутить с клавиатуры. На телефоне меню открывается поверх карточки. При ширине 360 px горизонтального переполнения страницы в проверке нет |
| AC20. Тестовые данные | В проверенном пути из кабинета браузер загружал только локальные ресурсы. Самостоятельный режим интервью с конфигурацией шлюза доступен отдельно по `/?view=interview` |
| AC25, часть кабинета | Штатные Sidebar, Button, Input, Badge и Table импортируются экранами из локальных файлов реестра shadcn/ui. Мобильный Sidebar использует Sheet. Textarea и Sheet для самого интервью понадобятся в PR B |

Проверки на Windows выполнены через Codex с Node 26.13.0. Прошли установка по lockfile (`npm ci`), проверка типов, сборка, 35 модульных и серверных проверок. Playwright прошёл 18 сценариев в Chrome и те же 18 в Edge. Проверка API в самостоятельном интервью использовала тестовые ответы. Голосовая запись имитируется. Фактические проверки двух панелей интервью и превью относятся к следующему PR.

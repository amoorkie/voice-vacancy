# Публичный показ «Искры»

Этот отчёт фиксирует первую выкладку. Настоящий голос и автоматическое открытие описаны в [актуальной проверке](007-real-voice.md).

Адрес — https://amo0orkie.ru/iskra/. Публикация выполнена по поручению владельца после объединения PR #1–#10 в main.

## Проверенная сборка

- SHA кода — `3454bcfbc52c8505ed36a568ba353d927e4c292a`. Его сообщает [release.json](https://amo0orkie.ru/iskra/release.json).
- Проверки Application и Documentation для этого SHA завершились успешно.
- Перед выкладкой прошли типы, 38 тестов, сборка и 50 браузерных сценариев Chrome/Edge.
- На сервере работают отдельные Node 26.13.0 и voice-vacancy.service на 127.0.0.1:4327. Сборка клиента выполнена с базовым путём /iskra/.
- Архив проверен SHA-256. Nginx-конфигурация прошла nginx -t перед reload. Сервис портфолио active, его current до и после — `aee3e5559a0e45244a70723475a5de7b24807f2c`. Главная портфолио и /animix/ вернули 200.

## Публичный проход

В Chrome открыт настоящий HTTPS-адрес, ресурсы загрузились. Карусель листается стрелкой без нативной полосы. Четыре вымышленных ответа введены через редактор и подтверждены на круге. Запрос /iskra/api/vacancy вернул 200, появился редактируемый черновик. После изменения названия проверены буфер обмена и скачанный .txt. Превью проверено при 1440 и 390 пикселях. Возврат и подтверждённый выход прошли. Ошибок страницы и ответов HTTP 4xx/5xx при этом проходе не было.

[Публичная версия на компьютере](iskra-panels/public.jpg) · [На телефоне](iskra-panels/public-mobile.jpg)

Ожидание отдельно проверено при искусственно задержанном ответе на 1440 и 360 пикселях. Проверки axe A/AA и reduced motion прошли. Декоративные строки скрыты от диктора, статус и отмена доступны.

## Эксплуатация

[Размещение и откат](../technical/deployment.md) описывает каталоги, сервис, конфиг, счётчик API и порядок выпуска. Ключ хранится вне репозитория. Счётчик использованных попыток перенесён из локальной проверки и сохраняется между выпусками.

Запись и расшифровка работают на локальном примере, текстовая генерация — через API. Ответы и ручные правки хранятся в текущей вкладке.

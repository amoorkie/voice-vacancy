# Проверка выбранного экрана и общего прогресса

10.11.2026. Я перенёс выбранный «Светлый разговор» в существующий проект и уточнил A10: кольцо показывает подтверждённые темы. Основание и критерии — в [спеке UI](../technical/voice-interview-ui.md). Этот срез выходит отдельным PR поверх `codex/ui-reference-review` (основа `9763efc2247ccf30ad8165509ef2da7d39360d09`).

## Что изменилось

Я оставил в центре один вопрос, стеклянную кнопку и круг из 60 сегментов. После подтверждения каждой темы загораются ещё 15 сегментов: 0 → 25 → 50 → 75 → 100%. При переходах между темами заполнение сохраняется. Изменение подтверждённого ответа снимает его четверть до нового подтверждения; отмена правки возвращает её.

Полнота текущего ответа показана отдельно как N/M и число явно неизвестных пунктов. Запись, распознавание, ожидание и проверка не подтверждают тему автоматически. Подтверждённое «не знаю» завершает тему, но генерация по-прежнему может сообщить о недостатке сведений.

Текстовый редактор раскрывается по кнопке или вместе с расшифровкой. Сохранённый ответ виден при возврате. Я сохранил исправления, уточнение, сводку, редактирование черновика и экспорт из предыдущего прототипа.

## Границы результата

Это рабочий UI на тестовых данных. Настоящее аудио не записывается; рядом с микрофоном есть соответствующая подпись. Успешный ответ внешнего AI, качество распознавания и модельная оценка этим проходом не подтверждены. Статус своего шлюза остаётся в [предыдущем отчёте](002-owner-api.md).

Автоматические проверки охватывают заявленные сценарии, но не означают полную реализацию F001–F004. Визуальную приёмку владельца, пользовательское тестирование, merge и deploy этот отчёт не заменяет.

# Проверка первого прототипа

Дата: 10.11.2026. Код: `f2b9c5c66c40c087c76c341ffe39c546b06deb2c`. Основание — [срез M01–M08](../technical/mock-prototype.md). Последующие изменения этого PR добавляют отчёт и снимки, не меняя проверенный код.

Я начал с локального прохода на вымышленных примерах, чтобы проверить поведение до подключения моего API. Codex выполнил перечисленные ниже автоматические проверки и просмотрел снимки. Пользовательскую приёмку я проведу отдельно.

## Среда и результат

- Windows, Node 26.13.0, npm 11.20.0; версии зависимостей закреплены в lockfile.
- Chrome 156.0.8078.76 и Edge 157.0.4341.42.
- `npm ci --no-fund`: чистая установка прошла, audit сообщил о 0 известных уязвимостей на момент проверки.
- `npm run check`: typecheck, 22 unit-теста и production build прошли.
- `$env:TEST_BROWSER='chrome,msedge'; npm run test:e2e`: 10 сценариев в каждом браузере, все 20 прошли. Браузеры открывали собранное приложение через Fastify.
- `python scripts/check_docs.py` и `git diff --check`: прошли. Проверка документов повторена после добавления отчёта.
- CI выполняет установку, typecheck, unit, build, 10 сценариев в Chromium и проверку документов. Его фактический статус относится к опубликованному SHA в PR.

## Что проверено

| Критерий | Доказательство и граница |
| --- | --- |
| M01 | Чистая установка, сборка, запуск Fastify и браузерные проходы собранного приложения прошли |
| M02 | Серверные тесты проверили 503 `integration-disabled` на маршрутах обработки даже с `AI_ENABLED=true`. Полный браузерный проход не сделал внешних запросов. В клиенте нет обращения к микрофону; сервер запрещает его через Permissions-Policy |
| M03 | Проверены ширины 360/768/1440 без горизонтального скролла, reduced motion, переход фокуса на вопрос, Tab к записи, Escape и восстановление фокуса после диалога. Axe не нашёл нарушений WCAG 2 A/AA и 2.1 AA на начале, вопросе и результате. Это не полная проверка доступности |
| M04 | Четыре примера → проверка каждого → явное подтверждение → сводка → шесть редактируемых разделов → скачивание. Примеры не объявлены ответами модели |
| M05 | Unit проверяет версии/подтверждение/отмену и смену темы. Браузер проверяет одно уточнение, явное добавление с новой строки и сохранение своего текста при отказе от тестовой расшифровки |
| M06 | Ошибка и тайм-аут оставляют текст; правка во время ожидания отменяет применение результата. Unit дополнительно проверяет старый request ID, поздний ответ после сброса и отмену |
| M07 | Редакция черновика сохраняется, при изменении ответов появляется пометка устаревания. Скачанный UTF-8 файл содержит ручной текст и его статус. Источники привязаны к снимку генерации, а не к последующим ответам |
| M08 | Unit проверяет пустоту, предел 6000 Unicode code points, неизвестность, неправильные цитаты и схему. Произвольному тексту не присваивается оценка. Четыре «Пока не знаю» дают недостаточность и доступную сводку, а не вымышленную вакансию |

Во время проверки исправлены два дефекта: слабый контраст второстепенных подписей и смена источников старого черновика после повторного подтверждения ответов. Итоговые проверки выше выполнялись после исправлений.

## Что ещё не проверено

Настоящего микрофона, распознавания, модели, внешних API, сохранения на сервере и деплоя здесь нет. Не проводились проход со screen reader, пользовательское исследование понятности и оценка качества анимации в непрерывном просмотре. Автоматическая проверка фокуса не заменяет полный ручной проход только клавиатурой.

Это проверка первого среза, а не закрытие всех 103 критериев F001–F004. Реальная запись, контракты моего сервиса, стоимость, обработка данных, бюджетные ограничения и качество AI остаются последующими задачами. OpenAI не подключён и не выбран как провайдер.

# Документация Voice Vacancy

Документация развивается в том же репозитории и проходит через PR вместе с продуктом.

## Очерёдность

1. Исходный brief и границы задачи.
2. Исследование похожих решений по первичным источникам.
3. JTBD, пользовательский сценарий, предположения и риски.
4. Спецификации функций с критериями приёмки.
5. План реализации и небольшие PR.
6. Проверка результата и материалы сдачи.

## Статус

Основа репозитория создана. Исследовательские материалы и спецификации добавляются следующими PR. Приложение не реализовано, продуктовые гипотезы ещё не проверены на пользователях.

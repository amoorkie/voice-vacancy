## Что я уже проверил

Я использовал Codex для чтения задания, открытых первичных источников, ревью документов и создания локального прототипа на тестовых данных. F001–F004 и общие правила имеют статус accepted на основании product-v1. Принятие требований не означает выполненную реализацию или пройденную проверку AI.

## Как я проверяю документы

Команда `python scripts/check_docs.py` проверяет UTF-8, локальные ссылки и реестр спецификаций. Смысл требований и работу продукта она не проверяет. В ревью дополнительно сопоставляю требования, критерии и контрольные случаи; результаты указываю на конкретном commit SHA.

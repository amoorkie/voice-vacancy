# Последовательность PR и комплект сдачи

Я развиваю проект небольшими PR. Это порядок работы без обещания сроков; номера этапов не являются заранее выданными ID в GitHub.

Для F005 я начинаю с [бизнес-спеки](../specs/005-iskra-workspace/spec.md), по ней готовлю [план с JTBD, флоу и порядком PR](../specs/005-iskra-workspace/plan.md), затем [задачи](../specs/005-iskra-workspace/tasks.md). Ниже — первоначальная последовательность проекта F001–F004. Её [технический план](../technical/plan.md) и [очередь задач](../technical/tasks.md) сохранены для истории.

| Этап | Содержание | Условие перехода |
| --- | --- | --- |
| Основа, начальный commit | Git, README, инструкции, `docs` | Репозиторий доступен |
| Discovery PR | Brief, аналоги, JTBD, user flow, scope, процесс, docs-check | Решения приняты в product-v1; проверки на пользователях ещё впереди |
| Specs PR | Спецификации интервью, голоса, полноты и генерации | F001–F004 приняты; подготовить технический план перед кодом |
| Технический план | Стек, сервисы, контракты, обработка данных, бюджет и задачи | Подготовлен до подключения API |
| Каркас приложения | Запуск, CI и первый экран в принятом визуальном направлении | Сборка и экран со всеми ключевыми состояниями проверены |
| Интервью | Четыре темы, текст, редактирование, подтверждение, прогресс, сводка и экспорт | Сводка имеет полезный выход без генерации; текстовый срез ещё не закрывает BR-02 |
| Голос | Реальная запись и транскрибация, разрешения и восстановление | Реальный проход с микрофоном и контроль ошибок |
| Полнота | Рубрика и одно уточнение | Контрольные примеры и понятность человеку |
| Черновик | Опциональная генерация поверх сводки, редактирование и экспорт | Источники и пробелы видны; сохранены правки и выход при недостаточности данных |
| Приёмка и сдача | Полный проход, описание, презентация, отчёт о процессе, демо/видео | Все согласованные критерии имеют доказательства |

Полнота и генерация выделены отдельно, чтобы ошибки оценки не блокировали базовый сценарий незаметно. Текстовый срез помогает проверить flow, но до добавления настоящего голоса нельзя объявлять минимум исходного задания выполненным.

Я принял полную цель F001–F004 в [product-v1](../product/accepted-decisions-2026-11-10.md). Генерация обязательна как работающая возможность, хотя человек вправе забрать только сводку. Варианты min/medium и границы результата перечислены в [brief](../product/brief.md).

## Текущий результат

PR #1–#11 объединены в main. Кабинет, интервью и редактируемая вакансия опубликованы. Публичный проход с DeepSeek, правкой и экспортом выполнен. Перед выкладкой прошли 38 тестов и 50 браузерных прогонов.

Настоящий микрофон и серверное распознавание добавлены следующим срезом. Сохранение вакансии в действующей «Искре» остаётся следующей интеграцией. Презентация отдельным файлом пока не подготовлена.

В пункте 5 задания запрошен процент участия ИИ. Измерение доли не велось. В ответе описаны этапы участия Codex и решения владельца; численная оценка остаётся незаполненной.

# Интервью и понятный прогресс

ID: F001
Status: draft
Дата: 10.11.2026
Основание принятия владельцем: отсутствует.

## Проблема и пользовательская работа

Руководителю нужно последовательно сформулировать требования к роли и понимать, что уже подтверждено. Основания: BR-01, BR-03, BR-04; J1, J2, J3, J6. Ссылки: [brief](../../product/brief.md), [JTBD](../../product/jtbd.md), [flow](../../product/user-flow.md).

## Scope и нецели

Четыре фиксированные темы, один основной вопрос на экране, текстовый ответ, исправление и подтверждение, возврат к теме, обзор и круговой прогресс. Голос подключается через F002. Проверка смысла F003 и генерация F004 — отдельные функции. Нет регистрации, серверного хранения, публикации и оценки кандидатов.

## Требования

- **F001-R1:** введение объясняет результат, число тем и отсутствие сохранения после закрытия/перезагрузки. Микрофон не запрашивается при открытии страницы.
- **F001-R2:** темы и предлагаемые формулировки следуют таблице Q1–Q4 в user flow. Вопрос имеет краткую подсказку без навязывания примера как обязательного требования к сотруднику.
- **F001-R3:** текстовый путь доступен на каждой теме. Пустой ответ после удаления пробельных символов не подтверждается. Предлагаемый предел текста одной темы — 6000 Unicode code points, а не байтов; при превышении текст сохраняется в редакторе, подтверждение недоступно, причина видна. Число — проектный лимит, не требование brief.
- **F001-R4:** переход «Далее» подтверждает текущую версию ответа. Автоматического перехода от тишины, остановки записи или результата ИИ нет. В минимальном режиме непустой ответ достаточен; режим не заявляет смысловую проверку.
- **F001-R5:** можно вернуться к теме. Изменённый ответ требует повторного подтверждения; остальные ответы сохраняются. «Отменить изменения» восстанавливает последнюю подтверждённую версию и её статус. До подтверждения новая запись или текст не уничтожают старую версию.
- **F001-R6:** кольцо отражает только число подтверждённых тем 0–4, подпись «Ответы подтверждены: N из 4». Значение изменяется после подтверждения или начала изменения подтверждённого ответа. Таймер, громкость и число символов не заполняют кольцо. Семантический статус F003 не меняет смысл этого кольца.
- **F001-R7:** весь путь доступен клавиатурой. Фокус после смены темы находится у её заголовка. Численное значение и текстовая подпись доступны вспомогательным технологиям. Состояния различимы без цвета; decorative motion отключается при reduced motion. Конкретная форма анимации определяется выбранным визуальным направлением.
- **F001-R8:** обзор доступен после подтверждения четырёх тем. Он показывает полный текст и пробелы, позволяет редактировать тему, при наличии F004 — создать черновик.
- **F001-R9:** при сбросе интервью пользователь подтверждает удаление текущего сеанса; отмена сохраняет данные. Обычный переход между вопросами не вызывает подтверждение удаления.

## Данные и переходы

Предлагаемый доменный контракт, без привязки к framework:

| Поле | Смысл |
| --- | --- |
| questionId | Стабильный Q1–Q4 |
| draftText | Текущий редактируемый текст |
| confirmedText | Последняя подтверждённая версия либо отсутствие |
| confirmed | Допускает включение темы в общий прогресс |
| revision | Монотонная версия содержимого для отклонения устаревших результатов |
| completeness | Отсутствует либо результат F003 для конкретной revision |

Состояния темы: empty → editing → confirmed. Редактирование confirmed создаёт рабочую версию и снимает подтверждение, но сохраняет confirmedText для отмены. Возврат без изменения содержимого не снимает подтверждение. Если пользователь отменяет изменения, восстанавливается и статус. При изменении revision проверка полноты и созданный черновик больше не считаются актуальными.

Хранение первого прототипа — память текущей страницы. Аудио обрабатывается отдельно по F002. Восстановление между устройствами и после перезагрузки исключено из этого draft-scope.

## Ошибки и восстановление

| Сбой | Поведение |
| --- | --- |
| Пустой ответ | Остаться на теме, показать причину рядом с редактором |
| Слишком длинный ответ | Не обрезать молча, сохранить редактирование, попросить сократить |
| Микрофон недоступен | Текстовый путь остаётся рабочим; подробности F002 |
| Проверка смысла недоступна | Не скрывать ответ и не блокировать текст; восстановление F003 |
| Уход/перезагрузка | Текущий сеанс теряется в рамках объявленного ограничения; не обещать несделанное восстановление |

## Критерии приёмки

- **F001-AC1 → R1,R2,R8:** на новом сеансе видны введение и четыре темы; после четырёх непустых подтверждений пользователь получает обзор с соответствующими текстами.
- **F001-AC2 → R3,R4:** пробелы не подтверждаются; короткий содержательный ответ подтверждается вручную; 6001 code points сохраняются в редакторе с объяснением лимита.
- **F001-AC3 → R5,R6:** после четырёх ответов прогресс 4/4; изменение Q1 делает его 3/4; отмена возвращает 4/4 и старый текст; подтверждение нового текста возвращает 4/4 и новый текст.
- **F001-AC4 → R6:** запись любой длительности без подтверждения не изменяет прогресс; пользователь видит название показателя, а не необъяснимый процент.
- **F001-AC5 → R7:** сценарий проходится только клавиатурой; подпись прогресса доступна screen reader; reduced motion сохраняет информацию без декоративного движения.
- **F001-AC6 → R5,R8:** изменение ответа помечает прежний черновик F004 как устаревший, но не перезаписывает его автоматически.
- **F001-AC7 → R9:** отменённый сброс ничего не удаляет; подтверждённый сброс возвращает 0/4 и пустые ответы.

## Проверка и ограничения доказательств

Автоматически проверять переходы состояния и расчёт прогресса, а не внутреннее устройство компонентов. Ручной проход: четыре темы, исправление, отмена, клавиатура, screen reader и reduced motion. Фикстуры голоса здесь не доказывают выполнение BR-02. Никакие проверки этой функции пока не выполнены.

## Следующие артефакты

Для принятой функции добавить `plan.md`, `tasks.md` и затем фактический `verification.md`. Планы и задачи не заполнены фиктивным содержимым: пока не принят scope и не выбран визуальный ориентир, детальная структура реализации преждевременна.

До первого кода нужно закрыть блокирующие вопросы релевантной спецификации и зафиксировать основание принятия в её метаданных и реестре. Репозиторий пока не имеет технической блокировки merge по статусу спецификации; это договорённость процесса, проверяемая review.

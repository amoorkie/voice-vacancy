# Первый проход без внешнего API

Дата: 10.11.2026. Status: accepted для этого среза. Основание — моя команда начать каркас и первый экран отдельным PR, проверить весь сценарий на тестовых данных и позже подключить мой API вместо OpenAI.

## Что я делаю в этом PR

Я собираю каркас React/Vite + Fastify и первый экран интервью, связанный с остальным тестовым сценарием. Четыре темы, текстовый ввод, подтверждение, возврат, сводка, пример проверки и редактируемый результат позволяют проверить путь целиком до интеграции. Это локальный прототип поведения; F002–F004 ещё не считаются реализованными с настоящим сервисом.

Внешний провайдер — мой API. Его протокол, авторизация, поддержка аудио, хранение и тарификация пока не заданы. Совместимость с OpenAI не предполагаю. SDK OpenAI, его ключи и платные вызовы в каркас не входят. Для текущего прохода стоимость API равна нулю; прежний сравнительный бюджет не является бюджетом моего сервиса.

## Тестовые данные и ограничения

- Тестовая запись имитирует состояния записи/ожидания и возвращает заранее написанный пример. Настоящий микрофон не запрашивается, аудио не записывается.
- Примеры подставляются только по явному действию. Верхняя пометка объясняет тестовый режим; у имитации записи и готового черновика есть собственные подписи.
- Проверка рубрики работает только для точных подготовленных примеров, включая общий ответ, дополнение и «Пока не знаю». Произвольный текст можно подтвердить без оценки; фиктивный смысловой балл ему не назначается.
- Тестовый генератор возвращает известный результат только для подготовленного снимка. Для неизвестных ответов показывает недостаточность; для произвольного набора — ограничение тестового режима и доступную сводку. Он не подменяет исходные ответы другими фактами.
- В раскрываемой панели проверки можно выбрать успешный результат, сбой и тайм-аут следующей тестовой операции. Отмена и поздний ответ не изменяют новую редакцию.
- В памяти вкладки остаются ответы и правки; обновление сбрасывает сеанс. Сводка и текущая редакция скачиваются в UTF-8. Обновление/закрытие и полный сброс не обещают восстановления.

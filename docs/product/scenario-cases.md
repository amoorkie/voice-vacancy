# Контрольные сценарии интервью

Дата: 10.11.2026. Статус: ожидаемое поведение для последующей спецификации и приёмки, не выполненные тесты приложения. Основания: [JTBD](jtbd.md), [flow](user-flow.md), [план проверки](validation-plan.md).

Я использую эти случаи как задания для будущей проверки. В ревью документов сопоставляю исходное условие, действие и ожидаемый исход. Во втором PR связываю их с критериями конкретных функций.

| ID | Работа и исходное условие | Действие | Ожидаемый исход |
| --- | --- | --- | --- |
| SC01 | J1/J8: базовый режим, генератора нет | Подтвердить четыре текстовых ответа | Обзор → сводка → копирование/.txt без AI; тип результата явно назван |
| SC02 | J1/J3: голос доступен | Записать ответ, исправить термин, подтвердить | Исправленный текст попадает в обзор; остановка записи сама не подтверждает тему |
| SC03 | J4: план одной темы неизвестен | Явно сказать/написать неизвестность | Тема подтверждается, неизвестное остаётся в обзоре и экспорте |
| SC04 | J4: все четыре ответа неизвестны | Завершить темы и попытаться получить вакансию | Неполный результат/недостаточность материала, дополнение или сводка; успех J1 не засчитывается |
| SC05 | J2: пустой ответ | Попытаться подтвердить пробелы | Остаться в редакторе, понятная ошибка, прогресс не меняется |
| SC06 | J4: недостаточный ответ, уточнение ещё не предлагалось | Дополнить после уточнения, снова получить пробел | Второго вопроса нет; можно подтвердить с видимым пробелом |
| SC07 | J8: проверка смысла недоступна | Выбрать продолжение без оценки | Текст сохранён, статус «Полнота не проверена», интервью не блокируется |
| SC08 | J6/J7: разрешение ещё ожидается | Перейти к тексту; разрешение приходит позже | Поздний stream освобождён; запись не начинается; текст не перезаписан |
| SC09 | J6: отказ/занятое устройство/обрыв записи | Выбрать текстовый путь | Существующий текст сохранён; неполное аудио не отправляется автоматически |
| SC10 | J7: в теме есть рабочий текст | Вернуться к другой теме и обратно | Рабочая и подтверждённая версии сохранены; остальные ответы не меняются |
| SC11 | J7: незавершённое аудио | Попытаться уйти; сначала отменить, затем подтвердить удаление | Отмена не теряет запись; подтверждённый переход прекращает запись/запрос и удаляет временное аудио |
| SC12 | J3/J7: расшифровка идёт | Изменить текст вручную до позднего ответа | Ответ старой версии не перезаписывает правку |
| SC13 | J7: запись идёт | Скрыть вкладку, затем вернуться | Запись остановлена без отправки; обработка только по явному действию |
| SC14 | J3/J5: подтверждены четыре темы | Изменить раннюю тему и отменить изменение | Подтверждения и кольцо меняются с 4/4 на 3/4, результат устарел; отмена возвращает текст, 4/4 и актуальность |
| SC15 | J5: черновик вручную отредактирован | Запустить новую генерацию и отказаться от замены | Ручные правки сохранены; повтор/ошибка также не удаляют их |
| SC16 | J8: генерация упала, отменена или вернула недостаточность | Отказаться от повтора | Доступны обзор, исправление и сводка; бесконечного обязательного повтора нет |
| SC17 | J5: источник изменился | Скачать прежний черновик | Текущая редакция сохранена, в тексте видима пометка устаревания; новая генерация требует нового снимка |
| SC18 | J4/J5: есть конфликт и желательное требование | Проверить обработанный результат | Конфликт не разрешён молча; желательное не стало обязательным; неизвестная зарплата не придумана |
| SC19 | J5/J8: копирование запрещено | Получить текст другим способом | Ручное выделение или .txt без потери текущей редакции и её статусов |
| SC20 | J7: интервью не завершено | Скачать текущие ответы, затем закрыть вкладку | В файле есть неподтверждённые/неизвестные пометки, аудио не включено; восстановление сеанса не обещано |
| SC21 | J7: есть ответы и черновик | Отменить полный сброс, затем подтвердить | Отмена сохраняет всё; подтверждение удаляет сеанс и возвращает 0/4 |
| SC22 | J6/J7: только клавиатура и reduced motion | Пройти основной путь, ошибку и экспорт | Все действия доступны; фокус предсказуем; состояние понятно без анимации |
| SC23 | J7: запрос ещё идёт | Подтвердить полный сброс и получить старый ответ в новой Q1 | Новый sessionId; результат предыдущего сеанса не применяется |
| SC24 | J6/J7: файл ещё собирается после остановки | Последняя часть увеличивает его сверх 10 MiB | Файл не отправлен; прежний текст и путь новой записи/текста сохранены |
| SC25 | J7: нажата остановка | Отменить до последнего события записи | Поздние данные не запускают отправку отменённого аудио |
| SC26 | J4/J8: модель вернула оценку | Получить повторный/пропущенный ID пункта либо чужую цитату | Весь ответ отклонён; текст и продолжение без оценки доступны |
| SC27 | J3/J4: инструмент назван без обязательности или как желательный | Проверить Q4 | Неуказанная обязательность не выдумана; желательное остаётся желательным |
| SC28 | J3/J5: генератор сослался на цитату | Указать существующий текст из другой темы/версии | Новый результат отклонён, прежняя редакция сохранена |
| SC29 | J5/J8: есть отредактированный черновик | Новая попытка возвращает insufficient-input | Прежний черновик не исчезает; видны причина и путь к сводке |
| SC30 | J7: повтор с теми же словами | Получить ответ первой отменённой попытки после повтора | Старый requestId не применяется, даже если текст совпадает |
| SC31 | J3/J4: включена оценка | Получить все present | Тема подтверждается только после явного действия пользователя |
| SC32 | J1/J4: мало исходных сведений | Сравнить только название/инструмент и одну конкретную задачу | Первое даёт недостаточность, второе допускает частичный черновик с неизвестным |
| SC33 | J2: min без оценки | Ввести, дописать и очистить первый ответ без подтверждения | Кольцо показывает 1/4, остаётся 1/4, затем 0/4; число подтверждений не меняется |
| SC34 | J2/J4: medium | Получить частичную оценку, затем изменить текст или отменить повтор | Блок полноты сначала показывает N/M, затем отсутствие актуального балла; кольцо отдельно следует текущим подтверждениям |
| SC35 | J3/J4: основной ответ уже есть | Ответить на уточнение голосом или текстом и добавить к ответу | Обе части сохранены; проверяется объединённый текст; отмена дополнения не меняет основу |
| SC36 | J3/J4: в рассказе есть исправление | Сказать «SQL обязателен; поправлюсь, только желателен» | Явное исправление сохранено без ложного конфликта; простое противоречие без исправления остаётся конфликтом |
| SC37 | J1/J4: регулярная работа или смена проекта | Указать отсутствие отдельного проекта в Q2 либо разные проекты в Q2/Q3 | Регулярная работа с вкладом допустима; разные периоды не создают ложный конфликт |
| SC38 | J1/J5: полные конкретные ответы | Сгенерировать текст из трёх задач, ограничения дежурств и названной зарплаты | Существенные сведения сохранены с источниками; отсутствие названия роли не удаляет известные условия |
| SC39 | J2/J6: основной путь | Пройти запись, ожидание и переход при обычном и reduced motion | Один вопрос и действие этапа; технических ID нет; анимация/фокус/отмена соответствуют принятому дизайну |
| SC40 | J4: неоднородный список требований | Назвать обязательность только одного из двух инструментов | Обязательность не распространяется на второй; Q4.3 отмечает пробел |

При логическом ревью я проверяю, что у каждого условия есть действие и определённый исход. Будущий код, настоящий микрофон, браузеры, screen reader и AI проверю отдельно с записью commit SHA и фактических результатов.
